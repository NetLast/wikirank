# WikiRank / ВікіРанг

Інструмент для перевірки та аналізу внеску учасників вікіконкурсів
(Вікімандри, Вікіцитати та будь-які інші проєкти MediaWiki).

## Можливості
- **Доступ лише за логіном і паролем** — ролі «адмін» та «журі»
- **Кількісний аналіз**: сума доданих байтів, редагування, сторінки —
  через API MediaWiki, загалом і по кожному проєкту окремо
- **Якісний аналіз**: оцінки журі, середня якість, підсумковий бал за
  **формулою, яку адмін задає для кожного конкурсу** (`bytes`, `edits`,
  `articles`, `quality`); режими вмикаються окремо або разом, якісний
  автоматично показує кількісний
- **Шаблон конкурсу**: вставте посилання на шаблон — інструмент знайде всі
  статті кампанії та автоматично витягне список учасників у межах дат
- **Коментарі журі** зберігаються з автором і датою
- Список учасників із посиланнями на внесок **у новій вкладці**
- **Експорт CSV** для протоколу журі (з BOM, відкривається в Excel)
- Прогрес-бари для тривалих перевірок
- Інтерфейс **українською та англійською**, підтримка будь-яких мовних розділів

## Структура
| Файл | Призначення |
|---|---|
| `app.py` | Flask-застосунок (сервер + вбудований фронтенд) |
| `test_app.py` | 40 pytest-тестів |
| `wiki-contest-analyzer.jsx` | Автономна React-версія (артефакт Claude) |
| `requirements.txt` | Залежності |

## Локальний запуск
```bash
pip install -r requirements.txt
python app.py            # http://localhost:5000, вхід: admin / admin
```
Після першого входу змініть пароль адміна в «Налаштування → Мій пароль».

## Тести
```bash
pip install pytest
pytest test_app.py -v
```

## Розгортання на Wikimedia Toolforge
1. Створіть інструмент на <https://toolsadmin.wikimedia.org> (напр. `wikirank`).
2. Увійдіть і станьте інструментом:
   ```bash
   ssh login.toolforge.org
   become wikirank
   ```
3. Скопіюйте код у теку вебсервісу:
   ```bash
   mkdir -p ~/www/python/src
   git clone https://github.com/<ваш-акаунт>/wikirank.git ~/www/python/src
   ```
4. Створіть віртуальне середовище **всередині контейнера вебсервісу**:
   ```bash
   webservice python3.11 shell
   python3 -m venv ~/www/python/venv
   ~/www/python/venv/bin/pip install -r ~/www/python/src/requirements.txt
   exit
   ```
5. Задайте секретний ключ (сесії переживатимуть перезапуски):
   ```bash
   toolforge envvars create SECRET_KEY "$(head -c 32 /dev/urandom | base64)"
   ```
6. Запустіть:
   ```bash
   webservice python3.11 start
   ```
   Інструмент буде доступний на `https://wikirank.toolforge.org`.

Примітки: Toolforge шукає об'єкт `app` у `~/www/python/src/app.py` — саме так
його названо тут. База — SQLite у домашній теці інструмента (`~/wikirank.db`);
для великих конкурсів можна перейти на ToolsDB (MariaDB). Оновлення коду:
`cd ~/www/python/src && git pull && webservice python3.11 restart`.

## Безпека
- Паролі хешуються (`werkzeug.security`, pbkdf2/scrypt)
- Формула обчислюється через безпечний AST-інтерпретатор — довільний код
  виконати неможливо (покрито тестами на ін'єкції)
- Адмін-маршрути захищені перевіркою ролі на сервері
